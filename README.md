# Elakkiya E — Portfolio

Production React portfolio built with Vite.

```bash
npm install
npm run dev
```

The dev server runs at http://localhost:5173. That address is also the personal-project deployment URL in `src/content.js` (`portfolioUrl`). Replace it when the site is deployed.

Resume download uses `public/Elakkiya_E_Resume.pdf`.

```bash
npm run build
npm run preview
```
